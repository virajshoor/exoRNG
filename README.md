## 🚀 Features

### 🎯 6 Powerful Generation Modes

1. **🔢 Number Generator**
   - Generate integers or decimals
   - Custom min/max ranges
   - Multiple numbers at once
   - Perfect for any numerical randomization need

2. **🎲 Dice Roller**
   - D4, D6, D8, D10, D12, D20, D100 support
   - Multiple dice rolls
   - Automatic sum calculation
   - Perfect for tabletop gaming!

3. **🪙 Coin Flipper**
   - Single or multiple flips
   - Statistics tracking (Heads/Tails count)
   - Great for quick decisions

4. **🎰 Lottery Number Generator**
   - Customizable pool size
   - Unique or repeating numbers
   - Auto-sorted results
   - Perfect for lottery picks or raffle draws

5. **🔐 Secure Password Generator**
   - Customizable length (4-128 characters)
   - Uppercase, lowercase, numbers, symbols
   - Cryptographically strong randomization
   - One-click copy to clipboard

6. **👥 Team Picker**
   - Random team generation
   - Fair distribution algorithm
   - Perfect for sports, group projects, or parties
   - Supports any number of teams
